## About

iArise brings sermons, faith-based music, scripture, and reflection into one calm, minimal daily-practice app. Open the app, listen, read, reflect.

Rebuilt from the ground up with a stunning new design and powerful new features — beautifully optimized for iPhone and iPad.

## Built with

Native iOS — Swift, SwiftUI, CloudKit, StoreKit.

**Co-founder + sole developer.**
